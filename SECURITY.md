# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected security or privacy issue in a public GitHub
issue.

Use GitHub's **Security** tab and select **Report a vulnerability** if private
vulnerability reporting is enabled for this repository. Otherwise, contact the
repository owner privately through their GitHub profile.

Include a concise description, affected files or versions, reproduction steps,
and the potential impact. Do not include patient data, production clinic
details, credentials, licence information, or unsanitised ECGpro configuration
exports.

This is an independent community project. Vulnerabilities in AMEDTEC ECGpro or
AMEDTEC hardware should also be reported through the vendor's official support
channel.

## Supported versions

Only the latest revision on the repository's default branch is actively
maintained unless a release is explicitly marked as supported.
